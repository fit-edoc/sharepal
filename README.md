# SharePal

A Next.js clone of the SharePal gaming gadget rental page.

## Prerequisites

- Node.js (version 18 or higher)
- npm, pnpm, or yarn

## Local Setup

1. Open your terminal and navigate to the frontend directory:

```bash
cd frontend
```

2. Install the required dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. View the application in your browser:

Open http://localhost:3000

## Production Build

To test or run the production build locally:

```bash
npm run build
npm run start
```
